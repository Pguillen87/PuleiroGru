# Puleiro do GRU — produto Web

O Puleiro do GRU é o lugar onde os mascotes do aplicativo GRU nascem. Esta primeira implementação prova somente a experiência local `Entrada → Preparação → Reveal`, sem autenticação, pagamento, armazenamento ou integração com o Modal.

Princípio: **uma decisão funcional por vez dentro de um cenário rural vivo**.

O site Web, o aplicativo Android e o serviço Modal são camadas separadas. O site não altera nem incorpora a stack Android. Nesta fase, dados e tempos são demonstrativos e nenhuma geração real é iniciada.
