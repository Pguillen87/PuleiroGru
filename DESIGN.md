# Puleiro do GRU — sistema visual Web

Fonte visual oficial: Stitch `Puleiro do GRU — Visual Lab`, projeto `12428811857128735688`.

- Direção: Retro Rural Editorial + Cartoon Vivo.
- Display e marca: Bricolage Grotesque.
- Interface funcional: Inter.
- Palco rural ilustrado dominante; chrome discreto com tinta preta, vermelho editorial, papel quente e detalhes de catálogo.
- Um único sistema responsivo: palco primeiro; contexto muda de posição sem mudar de significado.
- Preparação mostra somente estado, status e orientação. Ações de escolha surgem apenas após o reveal.
- Targets mínimos de 48 px, foco autoral, status anunciável e alternativa completa para movimento reduzido.
- Textura nunca prejudica texto funcional; movimento é breve, intencional e dispensável para compreensão.
